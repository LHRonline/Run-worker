# Run worker 0.0.3c 发布说明

> 显示修复补丁，无功能变更，可直接覆盖安装 0.0.3b。

## 修了什么

### 设置页里弹窗被「盖住」

0.0.3b 加了「查看本次更新内容」按钮：在「设置 → 更新」里点它，会打开一个模态弹窗。
但这个弹窗的层级（`.overlay`，z-index 100）比全屏设置遮罩（`.settings-overlay`，z-index 120）低，
于是弹窗被设置页整个盖在下面 —— 你在设置页里完全看不到它，只有先关掉设置页、回到聊天界面，它才冒出来。

这正好就是「内容不在当前页面弹出，而在离开设置页面才弹出」的现象。

### 修复方式

把所有模态层（`.overlay`）的层级提到 `z-index: 130`，高于设置遮罩（120）、低于全局提示 Toast（200/300）。
这样不论从哪个页面打开弹窗（本次更新、确认框、删除提示、MCP / 知识库 / 记忆面板里的确认弹窗），
都会正确地盖在最前面。

### 排查结果

对「内容延迟到离开当前页才显示」这一类显示缺陷做了专项排查，确认：

- 设置页是全应用唯一的全屏不透明遮罩层，也是唯一会「盖住」弹窗的层级；
- 其它弹窗（确认框、删除提示等）与提示 Toast 本身层级正确，无遗留问题；
- 不存在其它同类遮挡 / 延迟显示缺陷。

## 受影响文件

- `src/renderer/styles/layout.css` —— `.overlay` 的 `z-index` 由 100 调整为 130，并补充层级说明注释
- `src/shared/presets.ts` —— 应用内「本次更新」面板内容更新为 0.0.3c

## 升级方式

- 从 [Releases](https://github.com/LHRonline/run-worker/releases) 下载 `Run-worker-0.0.3c-setup.exe` 双击安装；
- 或在已安装的 0.0.3b 里用「设置 → 更新 → 下载并安装」一键升级（自动 SHA-256 校验后静默安装）。

老数据无需迁移，可直接覆盖安装。
