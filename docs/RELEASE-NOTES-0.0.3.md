# Run worker 0.0.3

稳定性修复：集中修掉 0.0.1 / 0.0.2 里一批影响日常使用的已知问题。配置格式不变，`settings.json` 结构不变（version 仍为 1），历史对话、设置、定时任务全部保留，升级后无需任何迁移。

## 本版包含

- **切换会话不再串台**：选中新会话时若上一轮仍在流式输出，主进程先自动中断（abort）旧 run，再切换活动会话，避免思考 / 回答内容混入新会话。
- **运行期异常不再卡在「运行中」**：一次 `run` 的外层增加 `try/finally` 守卫，任何未预期的异常都会补发 `run:end`（status: error），界面不会永久停留在生成中。
- **定时任务跨月顺延有提示**：`0 9 31 * *` 这类在当月无该日期的表达式原本静默顺延且界面无提示，现在会在任务卡片展示「设定的每月 31 号在 2026年11月没有符合条件的日期，已顺延到 2026年12月31日」的说明。
- **Python 中文 / 含空格路径可正常执行**：Windows 下解释器路径含空格时自动加引号（spawn 的 file 参数），避免 `C:\Program Files\...` 这类路径启动失败。
- **浅色主题对比度提升**：工具调用卡片与错误文本改用更高对比度的变量，满足 WCAG AA，浅色模式下更易读。
- **错误提示标注渠道**：频率限制（429）等错误现在带上服务商展示名（如「渠道：DeepSeek」），便于定位是哪个 Key / 渠道触发。
- **模型列表兼容更多接口**：拉取模型列表时兼容只返回 `name` 不返回 `id` 的非标准 OpenAI 兼容服务，避免渠道测试误报；服务端异常时回退内置预设列表。
- **本地模型连接更稳**：对 ollama 等本地地址追加 `NO_PROXY`，避免被系统代理拦截；本地连接失败提示「请先运行 `ollama serve`」。
- **会话索引自愈**：启动时剔除指向已丢失会话文件的孤儿索引条目并写回干净索引，异常退出后偶发的「幽灵会话」不再出现。
- **渠道透传更完整**：主进程向 LLM 客户端透传服务商展示名，错误与重试上下文包含渠道信息。

## 安装

1. 下载 `Run-worker-0.0.3-setup.exe`（[Releases](https://github.com/LHRonline/run-worker/releases)）并双击运行。
2. 覆盖安装到原目录即可，设置、历史对话、定时任务全部保留。

完整说明见 [docs/INSTALL.md](INSTALL.md)，静默安装用 `/S /D=<目录>`。

## 校验

发布前跑过 `npm test`（22 项平台集成用例，含 8 项 0.0.3 新增）与 `npm run test:e2e`（27 项真实 Electron 端到端断言），均全绿：`ALL PASS (27/27)`。

- 平台集成用例 14 → 22：cron 跨月顺延 `nextNote`、会话索引孤儿清理、429 渠道标注、ollama 网络提示、模型列表 `name/id` 兼容与回退、python 路径引号、对话异常必补 `run:end`
- E2E 26 → 27：新增 F5 cron 跨月顺延 `nextNote` 提示

## 已知限制（余项）

- **无沙箱**：命令以当前用户权限真实执行，不是容器隔离（不在 0.0.x 范围）。
- **安装包未签名**：Windows SmartScreen 会提示「未知发布者」，可点「更多信息 → 仍要运行」；本版已支持人工比对 SHA-256。
- **MCP 需自备服务器**：`stdio` 传输会以当前用户权限执行你填写的 `command`，请只添加信任的服务器。
- **图像 / 视频 / 3D 需外部能力**：内置不含生成模型，需配置对应接口或 3D 生成类 MCP。
- **Electron 多屏缩放白屏**：特定多屏缩放组合下偶现白屏（后续版本修复）。
- **重复安装 PATH 重复**：极少数情况下重复安装可能写入重复 PATH 条目（后续版本修复）。
